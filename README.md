# Caja Callejera

Caja, inventario y resumen de ventas para un puesto de perros calientes y hamburguesas.

- **Vender:** pedidos mixtos en una sola cuenta, precios en $ con equivalente en Bs, 4 métodos de pago, referencia obligatoria en pago móvil/transferencia.
- **Inventario:** productos nuevos, precios, entradas de mercancía, alertas de reposición, productos que ya no se venden.
- **Resumen:** ventas por día de la semana, por hora, productos, métodos de pago y vendedor.
- **Banco:** conciliación de referencias contra el estado de cuenta.
- **5 perfiles:** Dueño, Encargado, Cajero, Almacén, Contador.

Abrir: `index.html` (redirige a `app.html` con versión para evitar caché).
Sincronización: pegar las credenciales de Firebase en `FIREBASE_CONFIG` dentro de `app.html`.
